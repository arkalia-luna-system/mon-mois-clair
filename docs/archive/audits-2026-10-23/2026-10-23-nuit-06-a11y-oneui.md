## 1. Risques S26 vs Ultra

Les deux phones sont **Compact** (&lt; 600 dp). Pas de branche `if (model == Ultra)` — correct. L’écart réel = **hauteur** + **largeur utile** (~360 dp S26 vs ~412 dp Ultra).

| Zone | S26 (cible n°1, ~6,3″ / ~780–832 dp haut) | Ultra (dev / second, ~6,9″) |
|------|-------------------------------------------|-----------------------------|
| **Chrome sticky** | `compactHomeChrome` : paddings 8 dp, Reste **34 sp**, épargne derrière **Plus** | Confort : paddings 12, Reste **~40 sp**, épargne visible |
| **Liste sous sticky** | Sticky + Plus ouvert + snackbar + barre Menu/+ = peu de factures visibles | Plus d’air ; faux positifs « OK » sur Ultra ne valident pas Senior |
| **FAIT ✓** | `widthIn(min = 88.dp)` compact — **sous** la charte « ≥ 96 dp » | 96 dp |
| **Grille jour 1–31** | 7×48 dp ne tiennent pas → FlowRow se replie ; plus de rangées avant Enregistrer | Moins de wrap ; Enregistrer plus souvent sous le pli |
| **Sheets** | `rememberSheetBottomClearance` (plancher 48 + 28) critique edge-to-edge One UI | Même code ; moins de stress hauteur |
| **fontScale ≥ 1,25** | Force déjà sticky « serré » même si hauteur &gt; 800 | Idem — bon ; mais hero en **sp** grossit encore (voir P0) |
| **Smoke** | **Pas en main** (AUDIT_STATUS) ; sim. 360×780 + texte 1,3 faite 2026-10-21 | Smoke partiel SM-S938B ; photo / sticky Plus / snackbar 6.73–6.75 à refumer |

**Lecture senior :** un Ultra « beau » peut masquer un S26 où Plus cache l’épargne, où le Reste à 200 % mange la liste, et où FAIT 88 dp est juste pour le pouce.

## 2. Checklist technique (code 6.75)

### Sticky
- Papier chaud `PaperWarm`, pas de logo/wordmark — OK charte.
- Mois ‹ › + calendrier : cibles `MonthStep` 48×48 ; libellé mois tapppable ≥ 48 haut.
- Courses / épargne : `StickyLinkRow` `heightIn(min = 48)` + semantics.
- Compact : épargne derrière **Plus** (accessible) — OK produit ; **découvrabilité** TalkBack / senior = risque P1.
- `AnimatedVisibility` Plus : OK ; état replié par défaut = liste prioritaire.

### Cibles 48
- `A11yTokens.minTouchHeight = 48.dp` + `Primary/Secondary/QuietLink/Danger` / hub rows / pastilles mois / jours grille.
- Grille : `size(48.dp)` + `indication = null` (évite gonflement Material ~64) — bon pattern One UI.
- Écart : FAIT compact **88** vs charte **96** ; QuietLink « Copier » / « Photo » = hauteur 48 mais **largeur = texte** (souvent OK, à fumer au doigt).

### Contrastes
- Tests : jour/nuit AAA (≥ 7:1) encre / muted / liens / boutons sur **crème / carte / warm** (nuit) — `WcagContrastTest`.
- Sticky = **PaperWarm** jour `#EDE8DC` : calcul audit —
  - InkMuted ~**7,8:1** OK  
  - DangerInk (déficit) ~**6,5:1** → **sous AAA 7:1** sur warm (OK AA ; tests ne couvrent que crème pour danger jour)
  - AccentWarn ~**6,9:1** sur warm (limite)
- Nuit InkMuted `#D1C1B1` distinct de Ink, ≥ 7:1 — OK 6.74.

### IME
- Accueil : barre Menu / + **cachée** si `imeOpen()` — OK zone pouce.
- Fiche : `imePadding` + `rememberFocusKeepsVisible` ; clavier ouvert → seul **Enregistrer** (Annuler / Supprimer masqués) — OK.
- Sheets Courses / Épargne : `imePadding` + clearance bas.
- Recherche Accueil : message vide **sous** le champ (évite masquage clavier Samsung) — OK historique C7.

### Sheets
- `contentWindowInsets = { 0 }` + `rememberSheetBottomClearance()` (Menu, mois, Courses, Épargne) — correct Galaxy edge-to-edge.
- `skipPartiallyExpanded = true` — moins d’états half-sheet confus TalkBack / senior.

### Night
- Palette `A11yTokens.Night` ; Apparence système / forcée ; widget aligné tokens.
- Smoke « bascule Clair à la main » encore ouvert (AUDIT_STATUS) — pas bloquant a11y code.

### fontScale
- `rememberDisplayFit` : si `fontScale ≥ 1.25` → paddings sticky min + Reste plafonné à **34** (base).
- **Piège :** `remainingAmountSp.sp` **re-scale** avec le système → à 1,5–2,0 le hero grossit encore. Sur S26 court, sticky peut écraser la liste (senior One UI « Grand » / « Très grand »).
- Cellules jour fixes en **dp** : le chiffre 1–31 peut **clipper** ou paraître serré à gros scale (hauteur case fixe).

### TalkBack (aperçu code)
- Lock : nav sous-jacent `clearAndSetSemantics` — OK.
- Live regions : erreurs, chargements, avertissements sticky — présents.
- Doublon possible : titre mois cliquable **et** icône calendrier = même action « Choisir un mois ».
- Labels courts **Plus** / **Moins** : OK si `onClickLabel` lu ; à vérifier au doigt.
