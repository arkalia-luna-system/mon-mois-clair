Confidentialité — Mon Mois Clair

App 100 % locale. Pas de compte, pas de serveur Mon Mois Clair, pas d’analytics.

Réseau

  • Aucune permission Internet dans l’app.
  • Aucun appel HTTP/API, aucune synchro cloud, aucune publicité.
  • Les intents « partager » / « mail » / « ouvrir PDF » passent par d’autres apps choisies sur le téléphone. Une fois hors de Mon Mois Clair, c’est leur politique qui s’applique.

Données sur l’appareil

OùQuoi
Base locale (Room / SQLCipher) Mois, factures, montants, notes, IBAN, chemins photos — chiffré au repos ; clé enveloppée Android Keystore.
Dossier Documents (SAF) Backups JSON enveloppe AES-GCM (code de copie) + médias locaux enveloppés.
Photos / PDF reçus Fichiers chiffrés dans l’espace app ; aperçu temporaire en cache.
Presse-papiers Communication / IBAN : marqués sensibles et vidés après ~30 s.

Pas de sauvegarde cloud Android automatique de l’app (allowBackup=false).

Ce n’est pas un coffre parfait. Après déverrouillage, les données sont en RAM / à l’écran. Code de copie oublié + téléphone mort sans autre copie = données perdues (pas de serveur de recovery).

Collecte / partage avec des tiers

Aucune collecte par Mon Mois Clair. Aucune donnée n’est envoyée à Arkalia, Google Play ni un serveur de l’éditeur via l’app elle-même.

Si tu installes via Google Play : Google traite l’installation / les mises à jour selon sa propre politique Play — indépendante de Mon Mois Clair.

Widget & notifications

  • Widget : affiche le Reste (montants masqués si verrou biométrique activé).
  • Notifications locales (rappels) : libellé + montant ; montant masqué si verrou ON.

Contact

Bug, idée ou question : dans l’app, Accueil → Menu → « Un souci ? Écrire à Arkalia Système » (mail via le client du téléphone).
