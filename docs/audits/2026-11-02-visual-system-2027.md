### Elevation

- Cartes liste / hero : ombre **2–4 dp** soft (pas glass)
- Bottom bar : **6 dp**
- Elevation tonale M3 : mid surface pour chips

### Type scale (inchangé structurellement)

- Display serif : Reste / montants
- Title / body / label sans ≥ 18 sp (a11y familiale)

### Icon style

Material Symbols **filled** mono-ink : chariot, tirelire, menu, settings, chevrons — tint composition locale.
